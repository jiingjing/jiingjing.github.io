Biological Information Transfer in Python

This project focuses on simulating the flow of biological information using Python. It involves parsing and analysing genetic sequences, simulating transcription and translation processes, and visualizing the resulting proteins. The project is designed to provide insights into the central dogma of molecular biology and the mechanisms of gene expression. \n You can read more about the project code and implementation details on the github repository.

Motivation

In preparation for my future studies in cancer genomics and data science, I completed MIT's Getting up to Speed in Biology on their Open Learning Library, and begun studying MIT's Fundamentals of Biology . I wanted to create a project that would allow me to apply what I had learned in a practical way.

Description

I decided to create tools for biological computation (of information transfer) written in Python. Users can interact with different components of the central dogma (DNA replication, RNA transcription, and translation) to understand how genetic information is processed in living organisms. I also included other relevant sequencing utility tools.

Features:

  • DNA/RNA sequence identification and validation
  • Base pairing of DNA/RNA sequences
  • Translation of RNA sequences to codons - accounting for reading frame and polarity
  • Translation of codons to amino acids
  • 6-frame and 3-frame translation
  • GC content calculator
  • Information transfer pipeline: DNA replication, RNA synthesis, and protein synthesis

Technical Details

The project is built using Python and intentionally does not leverages libraries such as Biopython. The code is structured to be modular and extensible, with the aim of making it easy to add new features or modifications to existing ones.

Unit tests (written using pytest) are automatically run on GitHub Actions.
