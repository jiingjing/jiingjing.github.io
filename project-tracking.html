Activity Tracking App

This project, called "Forget Me Not", is an app created to solve the issue I had of forgetting when I had last done a mundane task. It is an Android App developed with React Native and Expo, and allows the user to log and track tasks.

Technical Overview

  • Android App developed using Expo - a full-stack React Native framework
  • Testing and prototyping carried out with Expo Go and Android Studio's Android Emulator
  • Tools/Technologies: Expo, React Native, JavaScript, Visual Studio Code, Git, Android Studio

App Structure

Tasks Screen

  • Create new task
    • Choose task colour
    • Choose task name
  • Quick add a new log for a task for the current date and time, with just a tap/click
  • Add a custom task log (e.g. if you forgot to log an event you can select a custom date and time)
  • Edit a task's name
  • Edit a task's colour
  • Archive a task - remove it from displaying on the Tasks Screen, History Screen, and Calendar Screen (without deleting the task's data)
  • Delete a task and all of it's logs
  • View the last log for a task
  • Sort tasks alphabetically, from creation, or from last logged
  • Show or hide archived tasks
  • Choose date format and time format

    • History Screen

  • View a list of all tasks and all of their logs
  • Select a task and select logs to delete
  • Filter and select tasks

    • Calendar Screen

  • Displays logs as circles with the associated task's colour
  • Monthly view
  • Day view - list of logs for that date with option to delete a log

    • Archived Tasks Screen

  • List of archived tasks
  • Click to unarchive a task

    • Data Import/Export Screen

  • Import data as a csv
  • Export data as a csv
